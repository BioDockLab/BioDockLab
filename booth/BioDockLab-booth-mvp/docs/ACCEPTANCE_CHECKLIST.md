# MVP 인수 체크리스트

## 사용자 흐름

- [ ] 홈에서 연구 시작 버튼이 동작한다.
- [ ] 테마, 질환, 세포 모델 선택 상태가 표시된다.
- [ ] 1단계부터 6단계까지 오류 없이 이동한다.
- [ ] 이전 버튼으로 돌아가도 선택값이 유지된다.
- [ ] 새로고침 후 세션이 복원된다.
- [ ] 처음으로 버튼이 세션을 초기화한다.

## 출력

- [ ] 이름과 희망 직업이 리포트에 반영된다.
- [ ] 선택 질환과 후보 방향이 리포트에 반영된다.
- [ ] A4 리포트가 한 장에 출력된다.
- [ ] 카드 앞·뒤가 지정 크기로 출력된다.
- [ ] 프린터 배경 그래픽 옵션을 켰을 때 색상이 유지된다.

## 표현 경계

- [ ] 최적 약물, 치료 추천, 처방, 환자 맞춤 표현이 없다.
- [ ] 도킹 점수를 약효 순위로 설명하지 않는다.
- [ ] 오가노이드를 실제 장기와 동일하다고 설명하지 않는다.
- [ ] AlphaFold 화면을 실제 현장 계산으로 표현하지 않는다.
- [ ] 모든 결과 화면에 교육용 안내가 있다.
