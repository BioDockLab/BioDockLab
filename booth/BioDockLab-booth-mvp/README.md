# BioDockLab Booth Experience MVP

세포 → 오가노이드 → 단백질 구조 → AI 구조 예측 개념 → 후보물질 비교 → 연구 결과 출력으로 이어지는 **부스 운영·교육용 체험 웹앱**입니다.

## 현재 구현 범위

- 6단계 체험 플로우
- 연구 테마·질환·세포 모델 선택
- EGFR 단백질 구조 교육용 시각화
- AlphaFold 구조 예측 개념 비교
- 후보물질 3종 비교 및 연구 방향 선택
- 관람객 이름·희망 직업 기반 A4 리포트/연구원 카드 미리보기
- 브라우저 인쇄 기능
- 새로고침 후에도 선택 상태가 유지되는 localStorage 세션
- 의료 진단·처방으로 오해되지 않도록 교육용 경계 문구 적용

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173`을 엽니다.

## 기존 저장소에 넣는 방법

기존 BioDockLab 저장소 루트에 이 폴더를 `booth/`로 복사하는 방식을 권장합니다.

```bash
BioDockLab/
├─ booth/                 # 이 패키지 전체
├─ frontend/              # 기존 프로토타입
├─ backend/
└─ ...
```

```bash
cd booth
npm install
npm run dev
```

기존 프로젝트는 React 19 + Vite 구조이므로, 1차 단계에서는 기술 스택을 Next.js로 바꾸지 않고 별도 Vite 앱으로 격리했습니다. 기존 의료·연구관리 프로토타입을 훼손하지 않으면서 부스 버전을 병렬 개발하기 위한 결정입니다.

## 출력 테스트

1. 6단계 결과 화면으로 이동
2. 이름과 희망 직업 입력
3. `A4 리포트 출력` 또는 `연구원 카드 출력` 클릭
4. 브라우저 인쇄 미리보기에서 배경 그래픽을 활성화
5. A4 리포트는 A4 세로, 카드는 A4 용지에 명함 크기로 배치됨

실제 카드 전용 프린터 규격은 장비 확정 후 CSS `@page`와 카드 치수를 조정해야 합니다.

## 중요 경계

현재 수치와 후보물질 데이터는 **UI 개발용 예시 데이터**입니다. 교수 자문과 데이터 출처 검증을 거치기 전에는 실제 과학 데이터처럼 소개하면 안 됩니다.
