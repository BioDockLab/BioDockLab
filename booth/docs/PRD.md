# BioDockLab Booth MVP PRD

## 1. 제품 정의

관람객이 하나의 세포 기반 바이오 AI 연구 스토리를 체험하고, 선택 내용을 A4 연구 리포트와 AI Research Card로 가져가는 교육용 웹 프로그램.

## 2. 핵심 사용자

- 바이오·AI 전공 지식이 없는 일반 관람객
- 중·고등학생 및 대학생
- 체험을 안내하는 부스 운영자

## 3. 성공 조건

- 운영자 도움 없이 7–10분 내 완료 가능
- 1920×1080 화면에서 주요 정보가 잘리지 않음
- 신규 관람객을 위해 30초 내 초기화 가능
- 인터넷 장애 시에도 정적 데이터 기반 핵심 체험 가능
- 출력 버튼에서 A4 리포트 및 카드 인쇄 가능
- 의료 진단·처방·약효 예측으로 오해될 표현 없음

## 4. MVP 스토리

교모세포종 사례 → 2D 세포와 3D 오가노이드 비교 → EGFR 구조 확인 → AlphaFold 개념 체험 → 후보물질 3종의 구조적 참고 지표 비교 → 연구 방향 선택 → 결과 출력.

## 5. 비범위

- 실시간 AlphaFold 실행
- 실시간 도킹
- 실제 환자 데이터
- 개인 건강정보 수집
- 최적 약물 추천
- 실제 약효·독성 판정
- 사용자 임의 구조 파일 업로드

## 6. 과학 검증이 필요한 항목

- 대표 질환과 세포주/오가노이드 모델의 연결
- EGFR을 대표 단백질로 사용하는 설명 범위
- 실제 공개 구조 ID 및 구조 커버리지
- 후보물질 선정과 도킹 결과
- pLDDT 등 구조 신뢰도 표시값
- 한국세포주은행, ATCC, NCBI 등 데이터 출처 표기 및 이용 조건
