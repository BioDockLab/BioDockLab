# 팀 작업 분배

## 이영준 — PM / 제품 책임 / 통합 승인

- 요구사항·완료 기준 확정
- 화면 흐름과 데이터 스키마 변경 승인
- 교수 자문 항목 정리
- 주 1회 통합 시연 및 범위 통제
- 행사 직전 배포·인쇄·장애 대응 최종 승인

직접 구현 병목이 되지 않도록 기능 티켓을 상시 보유하지 않는 것을 원칙으로 합니다.

## 이승민 — 프론트엔드 리드

1. 이 패키지를 기존 저장소 `booth/`에 설치
2. 공통 Shell, Sidebar, Stepper 유지보수
3. 컴포넌트 분리 및 코드 품질 개선
4. 최종 빌드와 배포
5. 운영 중 초기화·전체화면 기능

## 김동하 — 데이터 / 출처 / 구조 파일

1. `src/data/content.ts` 예시 데이터를 검증 데이터로 교체
2. 질환·단백질·후보물질 출처 표 작성
3. PDB/mmCIF 구조 파일 확보 및 라이선스 확인
4. 데이터 스키마 문서화
5. 값이 검증되지 않았을 경우 화면에 `예시` 표시 유지

## 홍정우 — 기능 화면 / QA

1. 오가노이드 비교 화면 개선
2. 단계 이동과 localStorage 세션 테스트
3. 1920×1080, 1366×768 해상도 테스트
4. 키보드·마우스 입력 테스트
5. 버그 재현 절차와 완료 확인

## 김문수 — 콘텐츠 / UX / 운영

1. 모든 한국어 안내 문구 교정
2. 중학생도 이해 가능한 용어집 작성
3. 과장 표현 및 의료 오인 표현 탐지
4. 부스 진행 대본·FAQ 작성
5. 출력 리포트의 개인화 문장 작성
